# ⚽ Sport Performance Analytics

A Python-based sports analytics project that explores player and team performance using data cleaning, descriptive statistics, grouping, correlation analysis, and visualizations.

## 📌 Project Overview

This project analyzes football player performance metrics such as distance covered, passing accuracy, shots on target, tackles, turnovers, assists, goals, sprint count, and match result. It uses a sample dataset to demonstrate how data analysis can help compare player activity and explore performance patterns.

## 🎯 Objectives

- Inspect a performance dataset for missing values and duplicate records.
- Calculate minimum and maximum distance covered.
- Explore the distribution of players by position.
- Examine correlations between numeric performance metrics.
- Compare total goals by match result.
- Visualize sprint count by playing position.
- Compare sprint count and distance covered across players.

## ✨ Features

- **Data quality checks:** Count missing values and duplicate rows.
- **Descriptive analysis:** Find minimum and maximum distance covered.
- **Position analysis:** Count players by position.
- **Correlation analysis:** Generate a correlation matrix for numeric columns.
- **Match-result analysis:** Aggregate goals by result (Win, Loss, Draw).
- **Visualizations:** Create a bar plot for sprint count by position and a line chart comparing distance covered with sprint count.
- **Sample data generation:** Generate a small, randomized dataset and save it as a CSV file.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
```

Replace the URL and repository folder with your own GitHub details.

### 2. Install dependencies

```bash
pip install pandas matplotlib seaborn
```

If you want to run the script exactly as written in Google Colab, use a Colab notebook because it imports `google.colab.files`. For a local Python run, remove or adapt the Colab upload lines and ensure the CSV file is in the working directory.

### 3. Run the project

```bash
python "untitled5 (1).py"
```

**Note:** The current script first attempts to load the CSV and run analysis, then later generates a sample CSV. Therefore, the CSV must already exist before the script reaches the initial `pd.read_csv(...)` line. Alternatively, run the sample-data generation section first, then run the analysis section.

## 📊 Dataset Fields

| Column | Description |
|---|---|
| `Game_ID` | Match identifier |

| `Assists` | Assists |

## 📈 Analysis Workflow

1. Load the CSV dataset into a pandas DataFrame.
2. Check for missing values and duplicate rows.
3. Review the minimum and maximum distance covered.
4. Count players by position.
5. Calculate correlations among numeric columns.
6. Group goals by match result.
7. Plot sprint count by position.
8. Generate a randomized sample dataset and visualize sprint count against distance covered.

## ⚠️ Notes & Limitations

- The script generates only 10 randomized sample records; the results are for demonstration and should not be treated as real match statistics.
- Because data is generated randomly, output values and charts can change between runs.
- The script uses `Heart_Rate_avg` in the generated dataset, then drops that column during the earlier analysis if it exists.
- The current script order requires the CSV file to exist before the initial analysis starts. Run the data-generation block first or reorganize the script to avoid this issue.
- The Google Colab upload utility is Colab-specific.
